# Pulse

Track workouts, progress, and daily goals. This project is in development.

The dashboard shows sample stats for the week: workouts, minutes, streak, and daily goal. Workouts, Goals, Reports, and Settings are in place as pages.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

| Path | Page |
| --- | --- |
| `/` | Dashboard |
| `/workouts` | Workouts |
| `/goals` | Goals |
| `/reports` | Reports |
| `/settings` | Settings |
